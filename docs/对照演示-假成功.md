# 对照演示:假成功代价(三个场景)

> 同一页面、同一次点击,三种读法。零 LLM 成本,本地可复现。
> 复现命令:`python mcp/demo_false_success.py --case all --report`

## 结论一览

| 场景 | 动作返回时页面显示 | 后端实际 | 后果卡判定 |
|---|---|---|---|
| 显示成功但后端 422 | `✅ 注册成功!` | HTTP 422 | `errored` |
| 按钮变灰但请求 rollback | `处理中…` | HTTP 500 | `errored` |
| 202 后异步失败 | `✅ 已提交,任务排队中(202)` | HTTP 202, HTTP 500 | `unchanged` |

---

## 场景:显示成功但后端 422

| 读法 | 看到什么 | 结论 |
|---|---|---|
| **A 朴素 DOM**(无验证层) | `✅ 注册成功!` | **无失败信号** → 继续下一步 |
| **B 后果卡**(本项目) | `page_outcome=errored` / `situation=network_error` | ❌ 明确报错(有结构化原因) |
| **C 真值裁判**(agent 不可见) | `/external_facts.html?simulate=422 → HTTP 422` | 真相 |

- 动作返回时页面**显示**:`✅ 注册成功!`
- 后端**实际**:`/external_facts.html?simulate=422 → HTTP 422`
- 后果卡**判定**:`errored` — 操作引发后端接口报错: HTTP 422 http://127.0.0.1:54050/external_facts.html?simulate=422 — {"error": "email_taken", "message": "账号已存在"}

```json
[
 {
  "url": "http://127.0.0.1:54050/external_facts.html?simulate=422",
  "status": 422,
  "kind": "http_error",
  "detail": "{\"error\": \"email_taken\", \"message\": \"账号已存在\"}"
 }
]
```

## 为什么这值得看

朴素 DOM 读法拿到的是**页面自称的事实**;后果卡拿到的是**环境证据**(网络状态码)。
两者不一致时,只有后者能反驳前者。这不是模型能力问题——
后端 422/500 这些事实**不在页面的任何观察里**,再强的模型也推不出来。

> 对应核心命题 §2.2:需要「缺失的外部证据」的部分,不可能靠模型 scaling 凭空解决。

## 场景:202 后异步失败

| 读法 | 看到什么 | 结论 |
|---|---|---|
| **A 朴素 DOM**(无验证层) | `✅ 已提交,任务排队中(202)` | **无失败信号** → 继续下一步 |
| **B 后果卡**(本项目) | `page_outcome=unchanged` / `situation=none` | ⚠️ 未观察到生效证据(不假成功) |
| **C 真值裁判**(agent 不可见) | `/external_facts.html?simulate=202 → HTTP 202; /external_facts.html?poll=task&simulate=500 → HTTP 500` | 真相 |

- 动作返回时页面**显示**:`✅ 已提交,任务排队中(202)`
- 后端**实际**:`/external_facts.html?simulate=202 → HTTP 202; /external_facts.html?poll=task&simulate=500 → HTTP 500`
- 后果卡**判定**:`unchanged` — 目标区域无变化(点击可能未生效,或效果发生在远处)

- 3.5 秒后页面文本:`❌ 后台任务失败(3 秒后)`(异步结果不在动作窗口内)

## 为什么这值得看

朴素 DOM 读法拿到的是**页面自称的事实**;后果卡拿到的是**环境证据**(网络状态码)。
两者不一致时,只有后者能反驳前者。这不是模型能力问题——
后端 422/500 这些事实**不在页面的任何观察里**,再强的模型也推不出来。

> 本例后果卡给的是 `unchanged`/`uncertain` 而非 `errored`:
> 说明**异步结果不在动作窗口内**——这正是 Runtime 待补的「异步结果追踪」职责,
> 也是 A6 基准里尚未点亮的一条。

> 对应核心命题 §2.2:需要「缺失的外部证据」的部分,不可能靠模型 scaling 凭空解决。
