### 3.3 实时反馈闭环(核心能力,2026-08-31 集中落地)
这是相对旧版的最大功能增量,心智模型:CAD 图纸(结构空间)+ 网页视频(变更流)。

| 能力 | 内容 |
|---|---|
| 世界状态卡 | 所有工具返回自动附带 `status`(auth/dialogs/forms/page/frames + changed 高亮),登录态双信号检测(cookie 为主 + DOM 辅助) |
| world_changes 变更流 | 增量续读(游标 since/to)→ 重要性加权 → **结构化语义摘要 digest {counts, key}**(CAD 004# 圆孔原则:不强 ID 摘要不写人话,agent 用 world_entity 查详图) |
| world_click effect | 操作生效报告:点击前冻结区域 ±200px → 轮询 diff(聪明早停)→ verdict/confidence。含全页 dialog 兜底(远距弹窗)、目标状态翻转(aria-selected/expanded/checked)、URL 变化 |
| world_fill / world_press effect | 填表/按键同样返回生效报告(值进可见输入框验证,防 SPA 覆盖层静默成功) |
| world_wait | 事件驱动:内核 waitFor waiter + MutationObserver flush 命中即 resolve,替代轮询 |
| world_map | 页面结构导览:语义容器分区(街区锚点)+ 每区可交互入口(强 ID+指纹)+ 去重叠锚点 + 过滤空壳 |
| world_entities bounds | 空间矩形过滤(区域钻取):地图→钻取→详图闭环 |
| world_resolve | 弱 ID 解析:名字/强 ID/页面原生 id → 稳定编号 |

### 3.4 稳定指纹(第二 ID,2026-08-31)

### 弱模型验证发现的两个工具缺陷修复(2026-09-02)

### page_outcome 预合成情景判定(2026-09-01,弱模型计划 Step 1)

GitLab 实战盲区(提交后四信道无法判定)的根治:操作返回顶层新增 `page_outcome` 五态主标签,合并在 server 端完成,弱模型只读一个字段:

| 值 | 含义 | agent 应对 |
|---|---|---|
| progressed | URL 变化/导航前进 | 继续 |
| challenged | 阻断性中间态(遮罩+iframe 挑战) | 停止截图上报人工 |
| errored | 错误提示信号(role=alert/aria-invalid) | 读错误修正重试 |
| uncertain | 变化发生但性质不明 | 最多补一次 world_state |
| unchanged | 无有效变化 | 按失败路径 |

关键实现(采纳 Claude 评审修正):
- `_is_submit_trigger`:挑战检测只在"疑似提交动作"(form 内/type=submit)后启用,避免常驻遮罩组件(Stripe/地图)误报
- `_challenge_detection`:只认"fixed 全屏遮罩(≥25% 视口)+ iframe 子元素"强特征,不依赖提供商 URL 白名单(sandbox/焦点捕获仅作辅助证据)
- 主标签 + situation.evidence 结构(非严格互斥枚举,次要信号留给人/调试)
- `_build_page_outcome` 内嵌于 `_finalize_click_result`,world_click 返回即带

验证:`test_page_outcome.py`(挑战复刻→challenged、普通弹窗→不误判、负例→uncertain/unchanged 保守),收编进 offline 组。整体 16/16 无回归。

### Shadow DOM 穿透修复(2026-09-01,假设B 实测驱动)

弱模型假设 B 本地夹具证实:扫描器看不见 open shadow root 内部(组件内按钮/输入框全部缺失)——现代组件库页面会大面积失效。修复三处内核:

1. `engine/scanner.js`:`scanAll` 递归穿透 open shadow root(closed shadow 无法访问,已知边界)
2. `content/observer.js`:对每个 open shadowRoot 单独创建 MutationObserver 共享同一收集器;新挂载的 shadowRoot(懒加载组件)自动补观察
3. `engine/visibility.js`:`effectiveBackgroundColor` 祖先链跨 shadow 边界(跳 host 继续回溯)

验证:静态可见(shadow 内按钮/输入框进世界)+ 动态感知(运行期向 shadow 追加按钮 → world_wait 事件驱动命中 → 定位点击真实生效)。新增 `test_assumption_b_shadow.py`(静态)+ `test_shadow_dynamic.py`(动态),均收编进 offline 组。
顺带修复:3 个新测试的 `sys.exit` in asyncio 问题(会破坏退出码契约,导致流水线假失败)。
