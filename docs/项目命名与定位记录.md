# 项目命名与定位记录

## 最终名称

**Agent-Native Web**

中文名称：**智能体原生网页**

核心概念：**Agent-Native Web World（智能体原生网页世界）**

代码接口继续保留 `world_*`、`agentWorld` 和 `world_id`，用于兼容已有 MCP 配置和程序接口。

## GitHub 名称

建议仓库名称：`agent-native-web`

## GitHub 简介

让网页成为智能体可以直接进入和理解的世界：无需网站适配，直接暴露结构、空间、关系与状态。

## 一句话描述

把网页从给人观看的界面，变成智能体可以直接进入、理解和行动的世界。

## 完整描述

Agent-Native Web 是一套让网页成为智能体原生环境的技术方案。

它将网页的空间、语义、元素关系、空白区域和实时状态直接暴露给 AI 智能体，使智能体不再依赖截图猜测、坐标试错或反复读取原始页面结构，而是通过结构化世界进行感知、定位、行动和持续决策。

项目目前以浏览器注入内核、MCP 服务器和智能体技能包的形式实现，可将普通网页转换成智能体可查询、可操作、可持续感知的网页世界。

## 命名理由

“Agent Web Suite”只表达“有一组网页工具”，无法体现项目的原创方向。

“Agent-Native Web”强调网页不是被动等待智能体猜测的画面，而是主动向智能体公开自身结构和状态的环境。原始 Agent-Native HTML Demo 的“Living World（活的世界）”、空间坐标、关系图、目标缺口、世界记忆和增量观察，都是这个名称的概念来源。

当前浏览器扩展和 MCP 服务器，是把这一理念从专门设计的 HTML 页面扩展到普通网页的实现路径。
