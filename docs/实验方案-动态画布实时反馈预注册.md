## 0. 目的与三个可证伪命题

**总命题 P**：存在一类动态状态故障，静态快照验证对它（a）在因果上无法归因，或（b）只能以无界盲等代价检出；连续观测 + 事件溯源对两类故障均能确定性检出并驱动正确行为。

| # | 命题 | 类型 | 旗舰故障 |
|---|---|---|---|
| H1 | 在途闸门使重复副作用严格为 0（不变量） | 确定性 | 延迟可见（任意 D） |
| H2 | 短于采样周期的暂态（乐观回滚 τ<Ts）对快照存在采样盲区；连续观测检出率 100% | 确定性（附成本论证） | 乐观回滚 |
| H3 | 并发背景干扰下，单张快照无法归因（因果混叠）；事件溯源归因准确率 100% | 确定性（旗舰） | 竞态 |

**H3 的精确表述（对 Sol 原表述的修正）**：单张快照对"变化由动作还是环境引起"在信息论上不可判定；密集采样序列可做时间相关归因，但采样密度必须≥变化率且需精确时钟同步——等价于用轮询劣质地重造事件总线。因此价值主张为：**归因需要事件级溯源（带 cause 签名的变异事件），这是快照路线要么给不出、要么以无界成本给出的东西。**

## 1. Phase 0：机制验证（无 LLM，确定性断言）

观测层架构（采纳 Sol）：hook jexcel `setValue`/`updateSelection` 构建**脏矩形事件总线**，事件形如 `{x, y, old, new, ts, cause}`；配区域校验和兜底（我的方案 A，防 hook 遗漏）。注入器经 `window.__FAULT_INJECTOR__` 代理下发配置。

注入参数（预注册）：
- F1 延迟可见：D ∈ {0.5, 5, 30, 120}s
- F2 乐观回滚：立即成功色，τ=1.2s 回滚
- F3 背景自变：Poisson 过程，5 格/秒
- F4 静默丢失：选区丢包 30%

判据（全过才准进 Phase 1）：
- P0.1 归因准确率 100%（200 个事件 vs 注入器 ground truth）
- P0.2 回滚检出 5/5，标记 ROLLBACK_UNSTABLE
- P0.3 settled 事件：末次变化 ≤1s 内发出，静默期误报 0
- P0.4 闸门：盲重试脚本 10 连发 → 副作用恰 1（20/20 次）
- P0.5 时间戳精度 ≥ 注入间隔分辨率（ Sol 红线 #2 的正面验证）
- P0.6 稳态观测开销 < 30ms/tick

## 2. Phase 1：agent 行为实验（2×2 析因 + 剂量梯子子实验）

主实验（采纳 Sol）：任务 = 填 20×20 目标色块。
- 因素 A：反馈机制（A0 静态快照 / A1 Runtime：在途锁+增量事件流+稳定谓词+≤150 token 摘要）
- 因素 B：环境（B0 单纯延迟 2.5s / B1 复合：2.5s 延迟 + 20% 概率乐观回滚 + 2 格/秒噪声）
- n=10/组 ×4 = 40 次；A/B 交叉交替执行；温度 0.2；不透明运行代号（UUID）
- 统计框架：只主张"灾难性失效发生/阻断"（大效应量 h>1.2，Fisher 精确 α=0.01，功效 ≥95%）
- 预注册判据：B0 下 A0 重复率 ≥60% 且 A1 = 0%；B1 下 A0 误判回滚为成功 ≥50% 且 A1 = 0% 并暴露 UNCERTAIN

剂量梯子子实验（保留自我方案 A，弱主张）：闸门 off，D ∈ {0.5,5,30,120}s × n=5 = 20 次。
判据 R-ladder：0.5s 格 0/5 且 120s 格 ≥3/5 → 记"复现信号"；不单调 → 报告"视觉通道未复现"，禁止写"无效应"。

## 3. Phase 2：价值对比 + 端到端演示

- **2a 纯价值对比（承载主张）**：同一 F2 故障、同一动作；制度 α=快照（动作后 1s）vs 制度 β=连续观测。n=10/制度。判据：α 假成功 ≥9/10 且 β 检出 ≥9/10 → H2/H3 的价值分叉成立
- **2b 端到端演示（不承载主张）**：三色多边形 + 偶发回滚 + 背景扰动，配对 n=5；只报告完成率与无效动作差

## 4. 基线补丁对照（采纳 Sol 红线 #1，升格为正式实验格）

在 Phase 1 增加第三臂 A2：朴素补丁基线（动作后固定 sleep 2.5s 再快照），n=10。
- 若 A2 在 B0/B1 均达 0 重复且总开销劣势 <15% → 主张降级为"离散延迟快照已具工程充分性，连续观测的增量价值仅剩归因（H3 单腿）"
- 预算 +10 次运行

## 5. 确定性主张 vs 统计性主张（措辞锁定）

- 确定性（可小样本强结论）：闸门互斥、回滚检出、归因准确率、α/β 分歧
- 统计性（只报 Wilson 95% CI，结论限定当前模型）：重试耐心分布、token 节省百分比、UNCERTAIN 修复成功率
- 全部行为结论措辞限定"在该模型 + 该 harness 下"

## 6. 威胁效度（合并清单）

1. 命名污染：UUID 运行代号，prompt 零语义泄漏
2. 模型漂移：A/B 交叉交替执行抵消后端推理漂移
3. 截图通道：无缩放无抗锯齿渲染，快照时间戳绑定单调时钟与事件总线对齐
4. 同源反驳：ground truth 来自注入器而非观测层自身（两组件互证）
5. 视觉延迟可见性本身是反馈：由 B1 复合故障（回滚给假成功信号）对冲
6. 外部效度：结论限定可控媒介（写死于本协议）

## 7. 放弃/降级条件（合并红线）

1. **朴素补丁平替**（Sol）：A2 以 <15% 开销全过 → 降级为"归因单腿主张"
2. **时间戳倒挂**（Sol）：事件时序精度 < 注入分辨率 → 暂停，重写底座
3. **归因失守**（方案 A）：P0.1 < 95% → 观测层不可信，整体重设计
4. **操纵失效**（方案 A）：0.5s 格重复 ≥3/5 → 延迟参数重设计
5. **模型幻觉主导**（Sol）：模型收到 UNCERTAIN 后 >80% 仍宣称成功 → 实验退化为模型评估，Runtime 主张搁置
6. **β 检出 <5/10**（方案 A）→ 连续观测自身有洞，命题在当前观测层不成立

## 8. 预算

Phase 0 ≈ 半天（零 API）；Phase 1 = 50 次 + Phase 2 = 20 次 + A2 臂 10 次 ≈ 80 次运行 ≈ 2.5M tokens，单机一天。

## 9. 判决（能否真正达到目的）

**能，附四个前提**：
1. 主张措辞必须按 §0 的修正版（归因 = 事件级溯源 vs 无界成本采样；不是"快照不可能"）
2. Phase 0 必须先证明观测层对 ground truth 的独立性正确（否则循环论证）
3. 行为实验只承载大效应量失效检测，不承载比率估计
4. 红线 1-6 预注册，尤其红线 1（朴素补丁降级条款）——它使结论对"工程补丁反驳"免疫

**遗留风险（按严重度）**：jexcel hook 的事件时序精度（P0.5 直接检验）；agent 任务理解率；B1 复合条件下 A0 失败的机制归因模糊（可接受：价值主张不依赖单故障归因）。
