# 动态画布实验资产（B3 夹具 / A6 ②③ 观测原型）

## guardian.html — 守护模式（A6 ②③ 的观测原型）

状态矩阵持续被侵蚀（每秒 5 格，模拟页面自变），观察者每 500ms 对账：
diff → 归因（我的动作 vs 环境）→ 修复。含"回滚事故"注入：agent 填色 60 格后
2 秒被静默抹除 30 格，观察者当场检出并补齐。

- 对应 A6 差距表 ②"缺异步回滚观测"、③"缺异步结果追踪"的观测原型
- 对应核心命题 §7.15 C2 在途闸门的触发信号源
- 实测基线（2026-09-12，本地 file://）：侵蚀→修复 454/454，检测延迟
  平均 20ms / 峰值 34ms；回滚 30/30 当场捕获，事故区 60/60 完好

## cinema.html — 随机剧目盲读（结构化视频流 / 统一时间线充分性判据）

动画参数运行时随机化（物体数/颜色/速度/弹跳，页面不显示参数）。
观察者按颜色聚合每个 tick 的像素变化为结构化事件（时间戳/包围盒/质心，
暴露为 window.__feed）。agent 不用视觉、只读事件流即可重建
物体数量/轨迹/速度/弹墙/最近接近。

- 对应 B3"结构化视频流"夹具思路
- 给统一时间线一个可验收的充分性判据：事件流可重建状态轨迹
- 实测基线：121 事件重建 3 物体 / 速度向量 / 6 次弹墙 / 最近接近 t≈12.2s
- 已知传感器缺陷（数据自曝）：按颜色聚合会把同 tick 远距同色变化并成
  一个事件——change_digest 需要空间聚类
