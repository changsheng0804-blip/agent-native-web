## 1. 设计与被试

确定性策略（代替 LLM，协议修订 v1.1）：
S1 盲重试（5 连发 0.5s）/ S2 等 3s 再读 / S3 读判声明（耐心 5s）/ S4 等稳再判。
臂：A0 静态快照 / A1 Runtime（闸门 + 观测层通知）/ A2 朴素补丁（读前等 2.5s）。
环境：B0 延迟 2.5s / B1 延迟+20%回滚(1.2s)+噪声 / B1x 回滚窗口随机 0.5-6s。
A1 通知只来自页面 MutationObserver 观测层（环境真相只用于记分）。
每格独立种子，可复现。

## 3. 诚实修正（数据强迫的）

- S2/S3 的 A1 vs A0 fs 差异(5% vs 15-30%)是**回滚抽样不均衡的伪差异**:
  两臂 fs 均≈该格回滚发生率(声明于 3s,回滚于 3.7s,与臂无关)。结论:不消费反馈的策略,
  A1 与 A0 行为无差异(除闸门对 S1 的效果)。
- 一次性声明任务结构下,"settled 信号"与"盲等"都在猜未知失败窗口;等得久=单调更优,
  信号仅提供更早安全声明的效率价值,未转化为正确性收益。

## 4. 定位结论

Phase 1 把 Runtime 的价值主张收窄并坐实为三件:
1. **闸门**:在途重复副作用=0(等待做不到,只有状态感知的闸门能拦);
2. **观测**:回滚被 100% 看见(证据职责,事后可审计、可恢复);
3. **无界窗口恢复**:尚未在本轮(窗口≤6s)证得边际价值——需要 B1y(回滚尾部无界,30-60s)。

被证伪的两条主张(A2 不足、settled 胜盲等)正是预注册红线 #1 设计要防的过度工程——
数据诚实地触发了降级,避免了在"有界窗口"场景下建设不必要的复杂度。

## 5. 下一步(B1y,未跑)

回滚迟到尾部无界(如 30-60s):盲等固定时长必然假成功(窗口不可知),
连续观测+恢复(检出迟到回滚→补提交)应有边际价值。若 B1y 复现该差异 → C3/C4 恢复;
若不复现 → 主张进一步收窄为"闸门+观测"两腿。
